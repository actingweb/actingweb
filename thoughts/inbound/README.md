# inbound/ — unevaluated reports from outside this repo

Drop a report here when you found something in ActingWeb from **outside** this
repository — a consumer project, a downstream deployment, a security review
elsewhere — and you don't want to guess whether it is a bug, a todo or a plan.
Undated filename, a `slug.md` naming the symptom. Say in the body who filed it,
when, and what work it came out of.

Nothing here has been checked against the tree yet. That is the point.

Triage verifies every claim, then files what survives — usually
`../todo/<slug>.md` plus a row in `../todo/INDEX.md`, sometimes `../research/`
or a plan — and **deletes the report**. What gets filed is the record, and it
carries the attribution across.

This directory should normally be empty. This README is the signpost and stays.

Full conventions: `../README.md`.
