## Issues Found

### 1. The empty-answer delete reads the list names non-strictly
**Severity:** Medium
**Description:** A read fault in `list_all_lists()` answers `[]`, so a
replica list is not deleted, the debug line still says "replica value
removed", and no 503 asks the publisher to resend. `attribute_list_store.py`
warns against exactly this ("a caller deleting what it lists must not read
a fault as 'nothing to delete'"). Raised by codex and by `/code-review`.
**Location:** `actingweb/handlers/callbacks.py:1876` "`if property_name in remote_store.list_all_lists():`"
**Recommendation:** `list_all_lists(strict=True)` (or a targeted
existence check that raises), or call `delete_list` unconditionally; add a
test with the list read faulting.

### 2. `get_permissions_uncached` can still answer from the cache
**Severity:** Medium (owner-reachable only: `update_permissions` is the
owner's grant API; a narrow interleave)
**Description:** It pops the entry and then calls `get_permissions`, which
looks in the cache first; another thread's earlier storage read can refill
it between the two, so the merge the plan moved to storage can still start
from a stale override and write it back.
**Location:** `actingweb/trust_permissions.py:691` "`self._cache.pop(f\"{actor_id}:{peer_id}\", None)`" then `return self.get_permissions(actor_id, peer_id)`; used at `:778`.
**Recommendation:** read the bucket directly (factor the load body out of
`get_permissions`) and cache the result after the read.

### 3. The web UI's "wrong password" text is written for every 403 with a Basic header
**Severity:** Low
**Description:** The override keys on any 403 with a Basic header and an
empty body, so an actor with no passphrase (created through OAuth), an Auth
of another type, or an authorization refusal of a signed-in creator gets
"Invalid username or password ... close the browser", which cannot help.
**Location:** `actingweb/handlers/www.py:125-129` "`and response.status_code == 403`"
**Recommendation:** key on the Auth's own text (`"Invalid username or
password"`, `actingweb/auth.py:166,171`), carried through `AuthResult`.

### 4. The rollback's error log can name a row that is already gone
**Severity:** Low
**Location:** `actingweb/oauth2_server/client_registry.py:767-776`
**Recommendation:** say which step failed (row or token entry).

### 5. An expiring `BoundedDict` counts expired entries in `len`, `bool` and `==`
**Severity:** Low
**Location:** `actingweb/_bounded_cache.py:48` "It stays a dict, so ``== {}``, ``pop`` and ``clear`` behave as before."
**Recommendation:** drop expired entries in `__len__`/`__eq__`, or narrow the
docstring. A copy or pickle restarting the window is documented in the
plan's Notes.

### 6. The empty-body arm trusts any 2xx from the publisher's host
**Severity:** Low (the baseline has the same rule; the plan chose it)
**Location:** `actingweb/interface/subscription_manager.py:195-196` "`if not text:`"
**Recommendation:** consider requiring the publisher's content type for the
destructive arm too, on both paths.

### 7. The grant fetch takes only part of the baseline's decision
**Severity:** Low (the plan scoped it this way)
**Description:** A non-redirected 404 keeps the replica value (the baseline
deletes it), and a top-level array is stored as a list without the metadata
check the baseline makes.
**Location:** `actingweb/handlers/callbacks.py:1840` (the error return) and `:1890` (`isinstance(response, list)`)
**Recommendation:** share the baseline's single-subtarget decision; belongs
with the JSON-parsable text item in `subscription-subscriber-fault-hardening.md`.

### 8. Hygiene
**Severity:** Low
- `actingweb/handlers/oauth2_endpoints.py:242` the `ClientRegistrationError`
  branch repeats the catch-all below it.
- `actingweb/interface/trust_manager.py:487` `_standardize_peer_id` has no
  caller left.
- Flask `/www` with no provider no longer clears a stale `oauth_token`
  cookie (`flask_integration.py:1801`, the early return skips
  `clear_cookie`).
- Test helpers without annotations: `tests/test_client_registration_trust.py:40`
  (`__init__` without `-> None`), the `spy` and the new test in
  `tests/integration/test_oauth2_flows.py`.
